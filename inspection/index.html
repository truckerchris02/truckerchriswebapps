Before you finish:
    How to use this inspection:
    1. Walk around the truck and trailer. For every item, tap OK if it is satisfactory, or tick Needs repair if it is not.
    2. When you tick Needs repair, explain it in the box — what is wrong, where it is, and how bad it is. That explanation prints on the report.
    3. Tap N/A only for equipment this rig does not have, such as a reefer or liftgate.
    4. At the bottom, choose the overall result, sign, then download a copy. Nothing is kept in this browser — use Save to download a copy you can file or share.
